# detourZero
Détour Zéro apps - essence
Au premier lancement, Safari demande l'autorisation de géolocalisation — acceptez pour que la position actuelle se remplisse automatiquement. Vous pouvez aussi la modifier ou la saisir manuellement (latitude,longitude).
Renseignez la destination et la marque, choisissez le rayon de détour et éventuellement "Ouvertes uniquement à l'arrivée", puis appuyez sur Rechercher.
Les résultats et les repères sur la carte se mettent à jour instantanément quand vous changez le rayon ou la case "ouvertes uniquement" ensuite : ces deux filtres ne relancent pas d'appel réseau, seule une nouvelle recherche (bouton Rechercher) le fait.
